상황

SQL을 다 짠 뒤 보고서에 넣을 개념적 ERD가 필요했습니다. 직접 그리지 않고 코드를 넣으면 그려 주는 도구를 찾았습니다.

AI에 준 조건
  • "내가 그리는 게 아니라 코드를 첨부하면 그걸 토대로 만들어주는 사이트를 추천해 달라는 거야"로 요구를 다시 좁힘
  • Mermaid에서 난 오류(Parse error … CHAR(5))를 그대로 붙여 질문
  • AI가 개체와 관계만 그린 간단한 버전을 주자 "내 컬럼까지 다 나와야 해"라고 요구
AI의 답과 이어진 작업

AI는 Mermaid가 CHAR(5)의 괄호를 도형 문법으로 읽어서 난 오류라며 라벨을 큰따옴표로 감싸게 고쳤고, 4개 테이블의 모든 컬럼과 PK·NOT NULL이 들어간 버전을 다시 만들었습니다.

문제 21 · 4개 테이블 JOINGitHub ↗
SELECT a.이름, c.센터명, j.업무명
FROM 근무 g
JOIN 알바생 a   ON g.알바생ID = a.알바생ID
JOIN 물류센터 c ON g.센터ID   = c.센터ID
JOIN 업무 j     ON g.업무ID   = j.업무ID;

문제 23 · GROUP BY + HAVINGGitHub ↗
SELECT 알바생ID, SUM(급여)
FROM 근무
GROUP BY 알바생ID
HAVING SUM(급여) >= 700000;
